ПАСПОРТ СИСТЕМЫ
Среда: Ubuntu 22.04.5 LTS в WSL2 (не отдельная VM Multipass).

1. Пользователь и права
Команда: whoami && id
Результат:
student
uid=1000(student) gid=1000(student) groups=1000(student),4(adm),24(cdrom),27(sudo),30(dip),46(plugdev)
Пояснение: student — текущий пользователь; id показывает UID, основную группу и дополнительные группы.

2. Ядро системы
Команда: uname -a
Результат:
Linux DESKTOP-IM2BAM6 6.18.40.1-microsoft-standard-WSL2 #1 SMP PREEMPT_DYNAMIC Fri Jul 31 22:12:15 UTC 2026 x86_64 x86_64 x86_64 GNU/Linux
Пояснение: команда показывает имя системы, версию ядра и архитектуру. Ядро относится к WSL2.

3. Версия ОС
Команда: cat /etc/os-release
Результат:
PRETTY_NAME="Ubuntu 22.04.5 LTS"
NAME="Ubuntu"
VERSION_ID="22.04"
VERSION="22.04.5 LTS (Jammy Jellyfish)"
VERSION_CODENAME=jammy
ID=ubuntu
ID_LIKE=debian
Пояснение: установлена Ubuntu 22.04.5 LTS, кодовое имя Jammy Jellyfish.

4. Время работы и нагрузка
Команда: uptime
Результат:
19:15:39 up 1 min, 1 user, load average: 0.02, 0.01, 0.00
Пояснение: показывает время работы системы, число пользователей и среднюю нагрузку за 1, 5 и 15 минут.

5. Оперативная память
Команда: free -h
Результат:
               total        used        free      shared  buff/cache   available
Mem:           7.5Gi       386Mi       6.6Gi       4.0Mi       525Mi       6.9Gi
Swap:          2.0Gi          0B       2.0Gi
Пояснение: показывает общую, занятую и доступную память, а также использование swap.

6. Использование дисков
Команда: df -h
Результат:
Filesystem      Size  Used Avail Use% Mounted on
/dev/sdd       1007G  1.3G  955G   1% /
C:\             953G  869G   85G  92% /mnt/c
Пояснение: df -h показывает размер файловых систем, занятое и свободное место. В WSL2 также видны подключённые системные точки монтирования.

7. Блочные устройства
Команда: lsblk
Результат:
NAME MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
sda    8:0    0 722.9M  1 disk
sdb    8:16   0  96.5M  1 disk
sdc    8:32   0     2G  0 disk [SWAP]
sdd    8:48   0     1T  0 disk /mnt/wslg/distro
Пояснение: показывает доступные блочные устройства и их размеры. Это устройства, видимые из WSL2.

8. Процессоры
Команда: nproc
Результат:
16
Пояснение: показывает количество процессоров, доступных текущему Linux-окружению.

9. Запущенные процессы
Команда: ps aux | head -20
Результат: первые 19 строк вывода включали процессы /sbin/init, systemd-journald, systemd-udevd, cron, dbus-daemon и текущую оболочку bash.
Пояснение: ps aux выводит процессы, а head -20 ограничивает вывод первыми 20 строками, включая заголовок.

Примечание:
Данные собраны в Ubuntu WSL2 на Windows. Они полезны для практики, но не подтверждают выполнение требования задания о входе по SSH в отдельную виртуальную машину Multipass.
